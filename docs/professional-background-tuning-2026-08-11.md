# 专业换色微调模式实现与验收报告

日期：2026-08-11

## 实现结论

H5 应用已增加专业换色微调模式，支持边缘收缩/扩张、边缘硬度、羽化和去色溢出四项参数。参数拖动会即时触发画布重绘，预览和最终导出复用同一套参数与像素处理流程。

同时补充了非安全 HTTP 上下文的资源 ID 兼容实现。当 `crypto.randomUUID` 不可用时，依次回退到 `crypto.getRandomValues` 和本地随机 ID，解决通过 `http://169.254.46.135:5173/` 访问后上传失败的问题。

## 处理方案

- `core` 定义平台无关的参数模型、默认值、范围限制和标准化逻辑。
- `plateform-h5` 对分割结果执行 Alpha 形态学收缩/扩张、边缘硬化、可分离羽化、边缘颜色传播和背景色溢出抑制。
- 预览按目标尺寸选择 256、512、1024 或 2048 档缓存，避免每次拖动都处理原始大图。
- 每张图片最多保留 12 份微调画布缓存，淘汰时主动释放画布内存。
- 默认参数直接复用模型原始抠图，避免无参数场景产生不必要的二次处理。
- 导出阶段读取与预览一致的参数映射，确保所见即所得。

- 本地背景移除模型运行成功；由于 HTTP IP 页面不是跨源隔离环境，ONNX Runtime 自动回退为单线程，不影响功能正确性。

- 重置后预览画布哈希与重新选择同一背景所得默认画布哈希一致，确认重置恢复默认参数。

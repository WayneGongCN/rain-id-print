# 业务规格照片裁切与单张导出实现说明

## 目标

原产品以冲印纸排版为主。本次在照片处理和纸张排版之间增加“规格与裁切”步骤，使同一份原图资源既能导出单张业务规格照片，也能继续参与单照片或多照片混合排版。

完整流程为：

1. 照片处理：上传、选择排版模式、换底和专业边缘微调。
2. 规格与裁切：逐张选择业务规格，调整缩放和位置，按照片独立 DPI 下载单张 JPEG。
3. 纸张排版：设置份数、纸张、间距、分隔线和整纸 DPI，下载冲印图。

单张导出结果不会重新作为排版输入。单张导出和纸张排版都直接使用原图、抠图缓存、蒙版微调和同一份归一化裁切框，避免二次 JPEG 编码。

## 分层实现

### `@rainnear/core`

- `PhotoLayoutInput.crop` 允许调用方提供照片级裁切框；缺省时继续使用居中 cover 裁切。
- `PhotoOutputRequest` 和 `PhotoOutputPlan` 表达单张业务规格照片的物理尺寸、像素尺寸、DPI、背景和裁切。
- `createPhotoOutputPlan` 校验源图、规格、DPI 和裁切比例，并通过毫米尺寸计算输出像素。
- `normalizeCrop`、`createZoomedCrop`、`translateCrop`、`getCropZoom` 和 `retargetCrop` 负责边界约束、焦点缩放和规格切换。
- 缩放范围固定为 1–4；规格切换保留裁切中心和相对缩放。

### `@rainnear/plateform-h5`

- `H5Platform` 增加 `renderPhotoPreview` 和 `exportPhotoJpeg`。
- 单张和整纸输出共享图片资源解析、抠图模型结果、专业微调、裁切绘制、JPEG 编码和 DPI 元数据逻辑。
- 单张输出不绘制分隔线，并沿用 2500 万像素安全上限。
- `H5ResourceStore` 不新增中间成片资源，调整裁切不会重新运行抠图。

### `@rainnear/app-h5`

- `AppPhoto` 增加 `crop` 和 `outputDpi`，每张照片独立保存规格、裁切、份数和单张 DPI。
- `App` 负责向导状态、平台副作用和导出流程；处理、裁切、排版和步骤导航拆分为受控组件。
- 裁切视口使用 Pointer Events 支持鼠标与触屏拖动，使用 `requestAnimationFrame` 合并高频状态提交。
- 第二步默认生成居中有效裁切，用户无需确认或下载即可进入排版。
- 单照片模式只排入首张照片；其他照片仍可提前编辑，切换混排后直接复用其状态。
- GA4 只记录步骤、规格、DPI、像素和背景模式，不记录文件名、资源 ID 或照片内容。

`@rainnear/plateform-miniapp` 本期仍为占位实现，只通过 `@rainnear/core` 获得可跨端复用的输出计划和几何类型。

## 输出边界

本期输出的是按业务规格毫米尺寸和用户 DPI 生成的 JPEG，不包含以下能力：

- 自动人脸检测、头部比例或眼位检查。
- 文件体积、色彩空间或线上受理渠道校验。
- 旋转、透视矫正、自由比例裁切。
- PNG、ZIP 批量导出或本地会话持久化。

因此界面和文档均不得承诺办证审核通过，用户应以实际办理机构要求为准。

## 验证

- core：验证默认裁切兼容、自定义裁切透传、缩放平移、规格切换和输出像素。
- H5 平台：验证单张裁切预览、无分隔线绘制、抠图模型复用和像素上限。
- H5 应用：验证初始化、规格切换、独立 DPI、安全文件名和分析事件隐私字段。
- 发布前执行 `pnpm test`、`pnpm typecheck` 和 `pnpm build:h5`，并在真实桌面与移动浏览器检查三步导航、触屏拖动及两类下载。
